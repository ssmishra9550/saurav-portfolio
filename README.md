# Saurav Kumar Mishra — Senior Full-Stack Portfolio

> Production-ready, modern, high-performance portfolio website built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Quick Start (Run Locally)

1. Open your terminal in this directory:
   ```bash
   cd C:\Users\User\.gemini\antigravity\scratch\saurav-portfolio
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Build for Production

To test the production build locally:
```bash
npm run build
npm start
```

## 🌐 1-Click Free Hosting & Deployment

### Option A: Vercel (Recommended — 2 Minutes, Zero Setup)
1. Push this folder to a GitHub repository (e.g. `github.com/your-username/saurav-portfolio`).
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository. Vercel automatically detects Next.js.
4. Click **Deploy**. Your portfolio will be live on `https://your-name.vercel.app` (you can also link your custom domain for free).

### Option B: Netlify
1. Connect your GitHub repository to [netlify.com](https://netlify.com).
2. Set build command to `npm run build` and publish directory to `.next`.
3. Click **Deploy**.

## 📝 How to Update Your Content

All text, contact information, project case studies, and skills are isolated in a single, easy-to-edit file:

📁 **`src/data/portfolioData.ts`**

- **Personal Info & Links:** Change phone, WhatsApp URL, email, location.
- **Projects & Case Studies:** Add, edit, or reorder projects (InsureTrack, TvServicePoc, Dynamics AX ERP, etc.).
- **Skills Matrix:** Add new technologies or frameworks.
- **Services:** Modify your service deliverables and pricing ranges.
